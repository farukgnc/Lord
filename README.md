# Lord

Lord is a Minecraft server core plugin that provides essential features for managing your server. It includes a robust rank and punishment system, chat management, and more. This project has been developed with the assistance of AI.

## Features

*   **Rank Management:** Create, delete, and edit ranks. Assign ranks to players with temporary or permanent grants.
*   **Punishment System:** Ban, mute, warn, and kick players. All punishments are logged and can be reviewed.
*   **Grant System:** Grant players ranks for a specific duration.
*   **Chat Management:** Manage chat channels and formats.
*   **MongoDB and In-Memory Support:** Choose between MongoDB for persistent storage or an in-memory database for testing.
*   **GUI Menus:** Easy-to-use GUI menus for managing ranks, grants, and punishments.

## Dependencies

*   [Paper API](https://papermc.io/)
*   [MongoDB Java Driver](https://mongodb.github.io/mongo-java-driver/)
*   [Jedis](https://github.com/redis/jedis)

## Installation

1.  Download the latest version of the plugin from the [releases page](https://github.com/your-username/Lord/releases).
2.  Place the downloaded `.jar` file into your server's `plugins` folder.
3.  Restart your server.

## Configuration

The plugin's configuration files can be found in the `plugins/Lord` directory. You can configure the database connection, messages, and other settings in these files.
